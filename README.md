# Data Analysis Projects using Python

This repository contains simple beginner-level projects on:

1. Diagnostic Analysis
2. Predictive Analysis
3. Prescriptive Analysis

All projects are developed using:

* Python
* Pandas
* Matplotlib
* Scikit-learn

---

# 1. Diagnostic Analysis

## Internet Provider Customer Churn Analysis

This project performs diagnostic analysis on internet provider data.

## Features

* Reads internet dataset using pandas
* Cleans missing values
* Checks signal quality using ping values
* Predicts whether customers will:

  * Continue with same company
  * Change company
* Calculates average internet speed by company
* Displays graphical analysis using matplotlib

## Technologies Used

* Pandas
* Matplotlib

## Concepts Used

* Data Cleaning
* Customer Churn Analysis
* Signal Quality Analysis
* GroupBy Analysis
* Data Visualization

## Output

* Customer churn status
* Average speed by company
* Bar graphs for analysis

# 2. Predictive Analysis

## Healthcare Disease Prediction System

This project predicts diseases based on patient symptoms.

## Features

* Reads healthcare dataset
* Converts symptoms into numerical data
* Trains a Decision Tree model
* Predicts disease using symptoms
* Searches patient details using patient name
* Displays disease prediction graph

## Technologies Used

* Pandas
* Matplotlib
* Scikit-learn

## Machine Learning Used

* CountVectorizer
* DecisionTreeClassifier

## Predicted Diseases

* Flu
* Cold
* Heart Disease
* Migraine
* Asthma
* Ulcer

## Output

* Patient symptoms
* Predicted disease
* Disease count graph

# 3. Prescriptive Analysis

## Hospital Bed Allocation System

This project performs prescriptive analysis for hospital patients.

## Features

* Analyzes patient condition
* Checks oxygen levels
* Prescribes:

  * ICU Bed
  * General Bed
  * Home Care
* Displays hospital allocation graph

## Technologies Used

* Pandas
* Matplotlib

## Logic Used

* Critical patients → ICU Bed
* Serious patients → General Bed
* Stable patients → Home Care

## Output

* Prescription recommendations
* Patient allocation graph
